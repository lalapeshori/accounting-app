# Accounting App

Complete accounting web application with frontend, backend, and database.

## Features

- **Frontend**: React 18 + TypeScript + Vite + Tailwind CSS
- **Backend**: Node.js + Express + TypeScript
- **Database**: PostgreSQL + Prisma ORM
- **Modules**: Authentication, Accounting, International Taxation, Cost Accounting, Reporting
